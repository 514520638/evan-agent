# 业务故事线

这里保存带来源和版本的跨任务业务契约。初始资产为 observed，只描述本次核对的源码／测试事实，并不代表用户认可所有现状或全部业务已覆盖。

- [会话身份与隔离](session-isolation.json)：聊天归属、登录实例隔离、过期／注销后的旧结果。
- [记忆人工审批](memory-approval.json)：编辑确认、取消、缺少审批器及身份过期。
- [流式结果与历史提交](streaming-history.json)：部分输出、完整成功、失败不提交历史。

新目标使用有用户来源的 confirmed 状态，尚未确认的方案使用 draft。稳定场景 ID 不应挪作其他含义。
输入格式、修订命令和 AC 关联见 [协议文档](../WORKFLOW_PROTOCOL.md)。源码或测试变化导致来源过期时先复核契约，再更新资产和任务引用。
