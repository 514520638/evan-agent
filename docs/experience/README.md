# 可复用经验

经验需有可定位证据、适用条件、反例、建议和实际结果；未经验证的观察保持 observed。
规划和失败归因时按关键词检索，复用前检查来源新鲜度。仅有任务流水或无适用条件的结论不进入这里。

- [逐用例证据](mapped-test-evidence.json)：整体命令成功不代表 AC 的映射用例已通过。
- [验证范围基线](docs-scope-baseline.json)：纯文档验证必须核对任务基线、工作树及暂存区。

默认检索排除来源过期、被替代、废弃及 reworked/rejected 经验，保留省略理由供进一步检查。
修订和 supersedes 替代关系见 [协议文档](../WORKFLOW_PROTOCOL.md)。
